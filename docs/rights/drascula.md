Status: **HOSTABLE / AUDITED FREEWARE SOURCE**

This record applies to the English freeware game-data package distributed by ScummVM. It does not cover separate music/language add-ons, trademarks, promotional artwork, or third-party repacks unless separately audited.

## Identity

- Title: Dráscula: The Vampire Strikes Back
- Developer/copyright holder identified by the freeware license: Alcachofa Soft S.L.
- Original release: 1996
- Platform used by this restoration: DOS
- Browser interpreter: ScummVM
- ScummVM engine/target: `drascula`

## Redistribution basis

The surviving Drascula freeware license explicitly permits free distribution on any medium if the readme and associated copyright notices/disclaimers remain intact. It permits a reasonable copying fee and aggregation in larger distributions, prohibits charging for the game itself, and permits modified game data when the modified work is prominently identified.

Abandonware uses the conservative path: it serves the verified original English freeware package without modifying its game data and preserves the package notice.

A preserved copy of the license is maintained in Gentoo's license collection:

https://github.com/gentoo/gentoo/blob/master/licenses/drascula

## Rights-holder/ScummVM release record

ScummVM's 6 September 2008 announcement records that Alcachofa Soft released Drascula as freeware after providing the project its sources, and that ScummVM received official permission to distribute the game.

https://www.scummvm.org/news/20080906/
