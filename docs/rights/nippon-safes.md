# Nippon Safes, Inc. — rights and provenance record

Status: **approved for audited hosted intake, pending package/build verification**

## Rights basis

On March 17, 2021, ScummVM announced the freeware release of **Nippon Safes, Inc.** after work with the original game authors Marco Caprelli, Paolo Costabel, Massimo Magnasciutti and producer Bruno Boz.

ScummVM's announcement states that both the DOS and Amiga versions were declared freeware **with permission to modify the files**, specifically making it possible to disable the original manual protection. This is direct preservation-specific authorization attributed to the original creators, not an abandonware inference.

Sources:

- https://www.scummvm.org/news/20210317/
- https://www.scummvm.org/games/
