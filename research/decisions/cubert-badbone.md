# Candidate decision — Cubert Badbone, P.I.

Decision: **HOLD — NO EXPLICIT THIRD-PARTY REDISTRIBUTION GRANT FOUND**

This decision applies to the exact ScummVM-hosted package audited by Abandonware. It does not claim that the original author could not authorize browser hosting later.

## What passed

The exact current ScummVM package was audited successfully:

- source: `https://downloads.scummvm.org/frs/extras/SLUDGE/cubert.zip`
- SHA-256: `594c2c88405d239be689526e3af94bf164c60a9d40e01bee53fdc64c2ba8051c`
- observed archive size: 11,089,204 bytes
- 13 safe archive members
- ScummVM engine/target: `sludge` / `cubert`

ScummVM currently publishes several Cubert Badbone packages and labels the title as a SLUDGE engine game. Historical and preservation sources consistently describe Cubert Badbone as freeware, and the original creator is Deirdra Kiai / Squinky (now Dietrich Squinkifer).

## What did not pass

The exact audited ZIP contains **no readme, license, copyright, copying, or other legal notice**.

The surviving external record supports that Cubert was released for free, but Abandonware did not find author-controlled wording that explicitly permits third parties to redistribute, mirror, or repackage the game data.

Those are different questions:

- **Freeware / free download:** supported.
- **Kodaxa may redistribute the game data from its own browser archive:** not established.

The open-source status of the SLUDGE engine does not license Cubert's game data, art, music, or scripts.

## Reconsideration trigger

This decision can be revisited if one of the following is found from Dietrich Squinkifer / Deirdra Kiai / Squinky or another legitimate rights holder:

1. explicit permission to redistribute or mirror the game,
2. an open-content license covering the game data and assets,
3. an author-controlled source/release repository with redistribution terms,
4. direct permission covering browser/WebAssembly hosting.

Another freeware listing, preservation mirror, or ScummVM package alone is not a reconsideration trigger.
