# Candidate decision — The Griffon Legend

Decision: **HOLD — NO EXPLICIT REDISTRIBUTION GRANT FOUND**

This decision is intentionally stricter than a generic freeware classification.

## What passed

The exact ScummVM-hosted package was audited successfully:

- source: `https://downloads.scummvm.org/frs/extras/Griffon%20Legend/griffon-1.0.zip`
- SHA-256: `0aad5fb10f51afb5c121cf04cc86539a6f0d89db85809f9e1767dfdc8d3191a4`
- package size observed by CI: 9,552,316 bytes
- 344 safe archive members
- flat game payload including `griffon.exe`, `griffon.bas`, `objectdb.dat`, and asset directories
- package notice found: `readme.txt`

ScummVM describes the game as freeware and distributes the exact package. The surviving original Syn9 site also presents the game as freely downloadable.

## What did not pass

The package's own `readme.txt` identifies Daniel Kennedy / Syn9 as the author, credits contributors, documents controls and configuration, and thanks players. It does **not** contain an explicit license, public-domain dedication, redistribution grant, or permission for third parties to rehost the package.

Under Abandonware's hosting policy, the following are supportive evidence but are not sufficient by themselves:

- a third-party preservation project calling a game freeware
- an official or original site allowing end users to download it
- source code or binaries being publicly available
- the absence of an objection to mirrors

The missing question is not whether the game may be downloaded for free; it is whether Kodaxa has a defensible basis to redistribute the game data from its own archive.

## Current status

- technical candidate: **yes**
- exact package provenance: **verified**
- package safety: **verified**
- freeware classification: **supported**
- explicit redistribution permission for our mirror: **not established**
- production manifest: **prohibited while this decision remains HOLD**
- public catalog: **do not add**

## Reconsideration trigger

This decision can be revisited if we find one of the following tied to Daniel Kennedy / Syn9 or another legitimate rights holder:

1. an explicit redistribution/mirroring license,
2. an open-content/public-domain grant covering the game data,
3. archived wording authorizing third-party redistribution,
4. direct permission from the rights holder.

A new package version or another abandonware/freeware listing is not, by itself, a reconsideration trigger.
